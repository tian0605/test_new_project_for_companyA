## 三、数据关系

```
碳配额(tCO₂e) = 政府发放 + 上年剩余 + 买入 - 卖出
CCER(tCO₂e) = 自有CCER + 买入CCER - 卖出CCER
绿证(kWh) = 买入绿证 - 卖出绿证 - 抵消绿证
碳排放量(tCO₂e) = 系统汇总（来自碳排放核算模块）
剩余可排放量(tCO₂e) = 碳配额 + CCER - 碳排放量
碳资产总额 = 碳配额 + CCER
```
