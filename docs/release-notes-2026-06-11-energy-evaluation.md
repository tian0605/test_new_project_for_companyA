# 2026-06-11 发布说明

## 概述

本次版本围绕节能评估能力建设完成了端到端落地，新增空间节能评估报告、可配置评价规则库、Excel 导出能力，以及对应的管理端维护入口与菜单权限支持。同时补充了产品碳模块和评估页面的若干文案与体验优化。

## 主要内容

### 1. 节能评估报告

- 新增空间节能评估报表接口 `/reports/spaceevaluation`
- 新增 Web 页面 `/space/evaluation`
- 支持按空间、产品、时间范围输出：
  - 产量
  - 吨标准煤
  - 吨二氧化碳排放
  - 单位产品综合能耗
  - 单位产品二氧化碳排放
- 支持趋势分析、评价结果、建议文字和 Excel 导出

### 2. 可配置评价规则库

- 新增评价规则主表与明细表：
  - `tbl_evaluation_rule_sets`
  - `tbl_evaluation_rule_details`
- 新增规则匹配引擎与规则 CRUD 能力
- 支持以下作用域：
  - 平台默认
  - 企业默认
  - 企业产品
  - 企业空间产品
- 初始化泷跃废旧涤纶再生项目默认能耗/碳排评价模板

### 3. 管理端支持

- 新增评价规则维护页面与路由：`settings.evaluationrule`
- 支持规则新增、编辑、导入、导出、复制、校验
- 优化规则明细弹窗布局，放宽最小值/最大值字段显示空间
- 将菜单权限模板中补充节能评估页面 `/space/evaluation`

### 4. Web 页面与导出优化

- 节能评估页面新增总结卡片、综合结论、趋势图优先展示、明细折叠
- 趋势图显示产量、单位产品综合能耗、单位产品二氧化碳排放，保留两位小数
- 优化顶部卡片的密度、留白和状态展示
- Excel 导出优化：
  - 显示产品名称
  - 报头、表头改为中文
  - 评价结果按中文说明输出

### 5. 菜单与文案调整

- Web 菜单文案：`产品碳足迹` 调整为 `碳排放管理`
- 页面文案：`评估` 调整为 `节能评估`
