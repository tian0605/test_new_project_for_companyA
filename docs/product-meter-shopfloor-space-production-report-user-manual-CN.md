# 产品-计量表-车间-空间-产量-离线表-报表全链路用户手册

## 1. 文档目的

本文档用于指导业务管理员和用户完成以下完整业务链路：

1. 维护产品主数据。
2. 将产品绑定到计量表或离线表。
3. 将计量表或离线表绑定到车间。
4. 将产品绑定到空间。
5. 用户在前台按产品录入产量。
6. 用户在前台录入离线表每日数据。
7. 用户在前台按产品查询空间侧报表。

本文档适用于当前版本中已经上线的产品隔离与企业隔离能力。

## 2. 适用角色

建议按以下角色分工执行：

1. 平台管理员或企业管理员：完成后台基础配置。
2. 企业用户：完成产量录入、离线表数据录入和报表查询。

## 3. 全链路关系说明

本次功能的核心关系建议按下面顺序理解：

1. 产品：用于区分不同产线、不同品类或不同生产对象。
2. 计量表/离线表：用于承接产品相关的能耗或介质数据。
3. 车间：用于组织现场设备、计量表和离线表。
4. 空间：用于组织报表统计范围，并作为用户查询与产量录入的主体。
5. 用户侧产量：用户在空间下、按产品录入产量。
6. 离线表录入：用户对已配置的离线表录入每日数据。
7. 报表查询：用户在空间报表页选择空间和产品，查看该产品对应的能耗、碳排、成本、负荷、统计和产量分析。

可参考如下业务理解：

- 一个空间可以绑定多个产品。
- 一个计量表或离线表可以绑定一个产品。
- 一个车间可以绑定多个计量表、虚拟表、离线表。
- 用户在前台选择空间后，系统会自动加载该空间已绑定的产品列表。

## 4. 使用前准备

在开始配置前，请先确认以下前提：

1. 已创建好企业、空间、车间、成本中心等基础数据。
2. 登录账号具备后台设置权限，以及前台空间数据查看权限。
3. 已明确每个产品对应哪一组计量表、离线表、车间和空间。
4. 若需要按产品看报表，必须先完成“空间绑定产品”和“计量表/离线表绑定产品”。

## 5. 后台配置流程

### 5.1 维护产品主数据

后台入口：`Admin > 设置 > 产品`

页面路由：`/#/settings/product`

操作步骤：

1. 登录 Admin 管理后台。
2. 进入“设置 > 产品”。
3. 点击“添加产品”。
4. 填写产品名称、计量单位、标签等信息。
5. 保存后检查产品是否出现在产品列表中。

建议填写规则：

1. 产品名称使用业务可识别名称，例如“产品A”“产品B”“甲线成品”“乙线半成品”。
2. 单位与产量录入保持一致，例如 `t`、`kg`、`件`、`m3`。
3. 同一企业内避免创建语义重复的产品名称。

【此处配图：产品列表页与“添加产品”弹窗】

### 5.2 给在线计量表绑定产品

后台入口：`Admin > 设置 > 计量表`

页面路由：`/#/settings/meter`

操作步骤：

1. 进入“设置 > 计量表”。
2. 在在线计量表列表中新增或编辑计量表。
3. 在表单中选择能源分类、能源分项、产品、成本中心等信息。
4. 保存后，确认计量表列表中“产品”列显示正确。

适用场景：

1. 某块在线电表只服务于某一个产品。
2. 蒸汽表、水表、气表等计量对象需要按产品隔离统计。

【此处配图：计量表列表中的“产品”列，以及编辑计量表时选择产品的表单】

### 5.3 给离线表绑定产品

后台入口：`Admin > 设置 > 计量表`

页面路由：`/#/settings/meter`

操作步骤：

1. 切换到离线表相关标签页。
2. 新增或编辑离线表。
3. 在表单中选择能源分类、能源分项、产品、成本中心等信息。
4. 保存后，确认离线表列表中“产品”列显示正确。

说明：

1. 当前版本已经支持离线表保存产品信息。
2. 离线表后续录入的数据，会通过该离线表归属到对应产品链路中。

【此处配图：离线表新增/编辑弹窗中的“产品”下拉框】

### 5.4 将计量表或离线表绑定到车间

后台入口：`Admin > 设置 > 车间`

页面中常用标签：`绑定计量表`

操作步骤：

1. 进入“设置 > 车间”。
2. 在左侧树中选择目标车间。
3. 打开“绑定计量表”标签页。
4. 在“表类型”下拉框中选择需要绑定的对象类型：
   - 计量表
   - 虚拟表
   - 离线表
5. 将右侧待绑定对象拖拽到中间“当前车间已绑定列表”。
6. 如需解绑，将已绑定对象拖到垃圾桶区域。

建议：

1. 一个车间内绑定的计量表、离线表应尽量保持业务边界清晰。
2. 如果离线表代表某个车间人工抄录值，应优先绑定到该车间。

【此处配图：车间设置页“绑定计量表”标签，展示表类型切换为“离线表”时的拖拽绑定界面】

### 5.5 将产品绑定到空间

后台入口：`Admin > 设置 > 空间`

页面中常用标签：`绑定产品`

操作步骤：

1. 进入“设置 > 空间”。
2. 在左侧空间树中选择目标空间。
3. 打开“绑定产品”标签页。
4. 将右侧产品列表拖拽到中间“当前空间已绑定产品”区域。
5. 如需解绑，将已绑定产品拖到垃圾桶区域。

说明：

1. 前台空间报表页和产量录入页，产品下拉框来源于该空间已绑定产品。
2. 如果空间未绑定任何产品，前台会提示“当前空间未绑定产品”或无法继续按产品查询。

【此处配图：空间设置页“绑定产品”标签，展示空间树、已绑定产品区、待绑定产品区】

### 5.6 检查空间、产品、计量对象的关系是否完整

建议至少完成以下检查：

1. 产品已经创建成功。
2. 至少一个在线计量表或离线表绑定了该产品。
3. 相关计量表或离线表已经挂到正确的车间或空间。
4. 空间已经绑定了该产品。
5. 用户具备 `/space/enterproduction`、`/space/production` 及相关空间报表菜单权限。

【此处配图：后台完成配置后的关系核对清单或系统页面组合截图】

## 6. 用户侧操作流程

### 6.1 产量录入

前台入口：`空间数据 > 产量录入`

页面路由：`/space/enterproduction`

操作步骤：

1. 登录前台 Web。
2. 进入“空间数据 > 产量录入”。
3. 选择空间。
4. 系统会自动加载该空间下已绑定产品。
5. 选择产品。
6. 选择报告期。
7. 点击“查询/Search”，加载当前日期范围内的每日产量记录。
8. 直接在表格中逐日填写 `Daily Value`，系统会逐条保存。
9. 若需要快速平均分配，可在上方“产量/Production”输入总量，再点击“提交/Submit”批量回填到当前日期范围。

页面行为说明：

1. 如果没有选择产品，系统会提示“请选择产品”。
2. 如果空间未绑定产品，下拉框会显示“当前空间未绑定产品”。
3. 产量录入是按“空间 + 产品 + 日期”维度保存的。

【此处配图：产量录入页，展示空间选择、产品选择、日期范围和每日产量表格】

### 6.2 离线表数据录入

前台入口：`计量表数据 > 离线表数据录入`

页面路由：`/meter/offlinemeterinput`

操作步骤：

1. 登录前台 Web。
2. 进入“计量表数据 > 离线表数据录入”。
3. 在下拉框中选择离线表。
4. 选择报告期。
5. 点击“查询/Search”，加载该离线表在所选日期范围内的每日数据。
6. 在表格 `Daily Value` 列中直接录入或修正每日值。
7. 系统保存成功后会提示“Successfully Saved”。

页面行为说明：

1. 离线表录入是按“离线表 + 日期”维度保存。
2. 如果前置日期存在空值且当前业务不允许跳过，系统会提示“Previous Data Is Empty”。
3. 当前页面不按产品筛选离线表，而是直接选择某一块离线表进行录入，因此前提是离线表本身已经在后台绑定了正确产品。

【此处配图：离线表数据录入页，展示离线表下拉框、日期范围和每日值表格】

## 7. 报表查询流程

### 7.1 空间产量能耗分析

前台入口：`空间数据 > 产量能耗分析`

页面路由：`/space/production`

操作步骤：

1. 进入“空间数据 > 产量能耗分析”。
2. 选择空间。
3. 选择产品。
4. 选择对比方式和统计周期。
5. 选择报告期与基准期。
6. 点击查询。

查询结果说明：

1. 报告期产量和基准期产量会按选中产品展示。
2. 单位产品能耗、单位产品碳排会基于该产品的产量和对应能耗自动计算。
3. 图表、汇总卡片和明细表均只反映当前“空间 + 产品”的结果。

【此处配图：产量能耗分析页，展示产品下拉框、汇总卡片和趋势图】

### 7.2 空间产品化报表查询

当前版本中，以下空间报表已经支持按产品筛选：

1. 空间能耗分类分析：`/space/energycategory`
2. 空间能耗分项分析：`/space/energyitem`
3. 空间碳排放分析：`/space/carbon`
4. 空间成本分析：`/space/cost`
5. 空间负荷分析：`/space/load`
6. 空间统计分析：`/space/statistics`
7. 空间对比分析：`/space/comparison`

通用操作步骤：

1. 进入对应空间报表页。
2. 选择空间。
3. 系统自动加载该空间可用产品。
4. 选择产品。
5. 选择统计周期、对比方式、报告期和基准期。
6. 点击查询。

通用查询规则：

1. 报表只统计属于当前产品的在线计量表和离线表数据。
2. 如果两个空间都绑定了同一个产品，空间对比分析会提供该产品作为公共筛选项。
3. 如果空间没有绑定产品，报表页无法正常进入产品维度查询。

【此处配图：空间能耗分类分析页，展示空间和产品双下拉筛选】

【此处配图：空间成本分析或空间碳排分析页，展示产品筛选后的图表结果】

### 7.3 当前暂不支持按产品筛选的报表

以下报表在当前版本会明确提示“该报表暂不支持按产品筛选，以避免产生错误结果”：

1. 空间能效分析：`/space/efficiency`
2. 空间节能分析：`/space/saving`
3. 空间计划分析：`/space/plan`
4. 空间预测分析：`/space/prediction`

建议：

1. 当前不要把这些页面作为产品隔离的正式统计口径。
2. 需要产品维度数据时，优先使用已经完成产品化的空间报表和产量能耗分析页。

【此处配图：暂不支持产品筛选的报表提示条】

## 8. 推荐业务操作顺序

建议实际业务按下面顺序上线：

1. 创建产品。
2. 给在线计量表和离线表绑定产品。
3. 将相关表绑定到车间。
4. 将产品绑定到空间。
5. 用用户账号进入“产量录入”按产品录入数据。
6. 用用户账号进入“离线表数据录入”补录每日值。
7. 在空间报表页按产品核对能耗、成本、碳排和产量结果。

## 9. 常见问题

### 9.1 前台看不到产品下拉框数据

排查顺序：

1. 检查当前空间是否已绑定产品。
2. 检查登录用户是否有该空间访问权限。
3. 检查浏览器是否拿到了 `/spaces/{space_id}/products` 返回结果。

### 9.2 已录入离线表数据，但产品报表没有结果

排查顺序：

1. 检查离线表是否已经绑定产品。
2. 检查离线表是否已经绑定到对应空间或其下属对象。
3. 检查查询时间范围是否覆盖录入日期。

### 9.3 产量录入后，产量能耗分析仍然为空

排查顺序：

1. 检查是否选择了正确空间和产品。
2. 检查产量是否已保存到所选日期范围。
3. 检查同一产品下是否已有对应能耗数据。

### 9.4 空间对比分析中没有可选产品

原因通常是：

1. 两个空间没有共同绑定的产品。
2. 其中一个空间尚未完成产品绑定。

## 10. 上线验收建议

建议按以下最小验收集进行核对：

1. 后台能新增产品。
2. 在线计量表和离线表都能保存产品信息。
3. 车间能绑定在线计量表和离线表。
4. 空间能绑定产品。
5. 前台“产量录入”能按产品录入成功。
6. 前台“离线表数据录入”能保存成功。
7. `空间能耗分类分析`、`空间成本分析`、`空间碳排放分析`、`产量能耗分析` 查询结果与预期一致。
